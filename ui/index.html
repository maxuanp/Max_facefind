        不读取/不写入系统 Chrome/Edge 默认配置目录，因此登录的是另一个账号，不影响你日常使用的账号。

站点

        

          
          
          
        

        
微博/小红书需要先在「账号状态」完成登录；遇到验证码会停止该站点任务。

      

      

        
阈值

        

          
          
          
          
          
          
          
        

        
图片墙「已丢弃」视图里的「改为通过」默认不受每人目标张数限制（manual_override_count=true）；
          如接口传 false，则超过 count 上限时会拒绝收录。手动收录会在索引中保留 manual_accept 标记，后续重跑不会被更严格阈值反向删除，可在成品墙撤销。

        
模型档位

        

          
          
          
        

        
模型加载失败会自动回退 buffalo_l / yolov8n-pose；切换档位后建议重新校准阈值。


        
构图过滤（只收全身 / 完整上半身）

        

          
          
          
        

        
默认 prefer_full_body：收全身与完整上半身，脸部特写/不完整上半身丢弃；坐姿/遮挡只标记不直接丢弃。

      

    


    

      
超分辨率

      

        
        
        
        
        
        
        
        
      

      

        GPU：检测中…
        权重目录：models/sr
      

      

      
超分结果保存到 data/sr/<人名>/，并写入索引与 metadata；原图路径和计数逻辑不变。
        模型与源见上方状态列表；SUPIR 需额外的生成式依赖与约 20GB 显存，未提供默认安装。
